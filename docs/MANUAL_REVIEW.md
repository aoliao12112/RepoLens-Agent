## 复核步骤

1. 对照 GitHub 仓库首页、许可证文件、目录树和近期提交。
2. 检查报告中的归档状态、主要语言、测试、许可证和最近活动。
3. 随机打开至少三条证据链接，确认链接属于目标仓库且能支持对应结论。
4. 把错误归类为采集、规则、模型解释、证据校验或展示问题。
5. 修复后重新运行同一案例，保留前后产物，不覆盖旧结果。
