# 60–90 秒演示脚本

1. **0–10 秒**：说明问题——采用开源项目之前，Star 数无法回答维护、工程、许可证和目标适配问题。
2. **10–25 秒**：输入公开 GitHub URL 与具体使用目标，说明模型开关可关闭。
3. **25–40 秒**：展示采集、审查、证据校验的任务进度；强调失败不会被包装成成功。
4. **40–60 秒**：打开四个审查章节，展示评分、事实/推断/待确认标签和一条证据链接。
5. **60–75 秒**：展示硬风险如何影响推荐等级，并完成人工风险确认。
6. **75–90 秒**：导出 JSON/Markdown，展示测试与评测产物，明确当前已知限制。

录制前必须使用已人工复核的仓库和成功产物。不得在演示中宣称尚未完成的 20 仓准确率或平均费用。
