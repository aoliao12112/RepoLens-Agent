# 开源参考与贡献边界

项目参考 OpenAI Agents SDK 官方 `research_bot` 示例的通用流程：规划检索、并行搜索和报告生成。

- 官方仓库：https://github.com/openai/openai-agents-python
- 示例目录：https://github.com/openai/openai-agents-python/tree/main/examples/research_bot

RepoLens 不把官方示例代码作为个人成果。个人实现重点包括 GitHub API 工具、仓库工程信号分析、许可证审查、证据模型、缓存、目标适配评分、评测集和 Web 服务。

如果后续复制或修改官方源码，必须保留其原始许可证与归属说明，并在修改文件中明确标注。
